📖 关于 JSON 可视化图谱

JSON 可视化图谱把复杂的 JSON 数据变成可交互的树形图，用鼠标可以展开、折叠、拖拽节点，直接修改属性。适合接口返回一堆看不清结构的嵌套 JSON 时，一眼看清层级，也可直接当作 JSON 编辑器用。

✨ 主要功能

  • 交互式树形图谱：鼠标单击节点展开/折叠，不同类型颜色区分（对象、数组、字符串、数字、布尔、null）
  • 自由缩放拖拽：画布可以缩放/拖动，大型 JSON 也能看到清楚的局部
  • 直接编辑修改：右键节点就能新增/删除/重命名属性，无需手写 JSON
  • 导入导出：支持从粘贴板、文件导入，导出为格式化 JSON 或紧凑版
  • 错误标注：不合法 JSON 会高亮提示具体行号
  • 本地处理：JSON 数据不上传服务器，完全在浏览器中解析

⚡ 使用步骤

  1. 把 JSON 文本粘贴到左侧编辑器，或直接拖拽 .json 文件到页面
  2. 右侧自动渲染为可视化树形图
  3. 鼠标拖拽画布、滾轮缩放，点展开图标展开/折叠任意层级
  4. 右键节点可以新增子属性、修改值、删除
  5. 导出方式：顶部导出按钮选择“格式化”或“压缩”后下载

🎯 适用场景

  • 接口调试：后端返回一堆嵌套 JSON，无法快速看清字段层级
  • 配置文件编辑：package.json / tsconfig.json / 应用配置中快速修改
  • API 文档阅读：将 Swagger / OpenAPI 返回的参数转为图
  • 数据模型设计：可视化设计类似 NoSQL 文档结构
  • 教学/分享：发给同事或学生一个直观的 JSON 图，比纯文本好理解

❓ 常见问题

Q：最大支持多大 JSON？
A：建议单个文件不超过 10MB，否则浏览器渲染会卡。超过 5000 个节点时建议默认折叠深层，需要时再展开。
Q：数据会上传到服务器吗？
A：不会。全部处理在浏览器本地完成，包含密钥、个人信息的 JSON 可以放心使用。
Q：支持带注释的 JSON（JSONC）吗？
A：目前遵循严格 JSON 规范，不支持 // 或 /* */ 注释。如果需要导入 JSONC，请先从内容中手动去除注释。
Q：能保存到云端后续接着编辑吗？
A：当前不提供云端存储（保护隐私）。建议导出为文件存到本地，下次重新导入。
Q：导入后提示“解析错误”怎么办？
A：工具会高亮错误行位置，常见问题：尾逗号、单引号（JSON 只支持双引号）、未转义特殊字符。修复后重新解析即可。
Q：导出的 JSON 字段顺序会变吗？
A：不会。导出时保持与可视化中一致的属性顺序，字段名排列同导入时一致。
