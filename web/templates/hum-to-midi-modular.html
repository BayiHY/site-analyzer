📖 关于哼唱转 MIDI 工具

哼唱转 MIDI是一个实时音高检测工具，你对麦克风哼唱旋律，它会实时将你的声音转化为音符并自动生成 .mid 文件，方便导入 FL Studio、LMMS、GarageBand 等音乐制作软件中编辑。

✨ 主要功能

  • 实时音高检测：基于自相关算法（YIN algorithm），延迟低于 50ms
  • 自动旋律分割：自动识别音符边界，无需手动划分
  • 灵敏度可调：支持调节音高容忍度、最短音符时长
  • 钢琴预览：哼唱的同时就能在钢琴上看到亮起来的那个键位
  • MIDI 下载：直接导出为标准 MIDI 文件，兼容所有常见音乐软件
  • 两种输入模式：麦克风哼唱 / 系统声音内录（支持录网上播放的音乐）

⚡ 使用步骤

  1. 选择输入模式：麦克风 或 系统内录
  2. 允许浏览器使用麦克风（首次使用会弹出授权框）
  3. 点击 “开始录制”，对麦克风哼唱你想记录的旋律
  4. 实时观察钢琴上高亮的音符，确认音高识别准确
  5. 点击 “停止”，写入文件名，下载 .mid 文件
  6. 将 MIDI 导入你熟悉的 DAW（FL Studio / LMMS / 钢琴 App）进一步编辑

🎯 适用场景

  • 灵感捕捉：脑中有个旋律，哼一下就变成可编辑的乐谱
  • 试听乐曲：想知道某首歌的主旋律是什么音，哼出来看钢琴键位
  • 作曲灵感存档：零碎旋律想法直接存为 MIDI，不丢任何旋律灵感
  • 声乐发声训练：声乐课的初学者可以直观看到音准不准
  • 乐器初学者听写练习：将音录中的单旋律扬写为乐谱

❓ 常见问题

Q：哼不准调也能用吗？
A：可以，工具会如实记录你的音高，不会自动“修正”。建议确保周围安静，且哼唱稳定（避免噪声、嗯声）。导出后可到 DAW 里手动拖动音符修正。
Q：支持多声部（和声）吗？
A：不支持。本工具针对单旋律优化，对同时发出多个音高的声音（如钢琴和弦）无法拆分。建议一次只哼一个声部，多次录制后在 DAW 中合并。
Q：为什么钢琴上看不到亮？
A：首先确认麦克风权限已授权，其次检查页面上方的“输入灵敏度”，较小声量需提高灵敏度。硬件麦克风比笔记本内置麦克风效果好很多。
Q：系统内录模式能录网上的歌吗？
A：能。选择“系统内录”后，浏览器会弹出屏幕共享授权框，选择包含音频的页卡（如 YouTube、B 站）即可。仅支持 Chrome / Edge 桌面版。
Q：导出的 MIDI 能导入 FL Studio / LMMS / Cubase 吗？
A：能。使用标准 MIDI 1.0 格式，兼容所有主流 DAW。
Q：为什么哼高音时识别不准？
A：人声在高音区（高于 C5）容易产生波形不稳定，建议使用下降一八度哼唱，后期在 DAW 中整体上移即可。
