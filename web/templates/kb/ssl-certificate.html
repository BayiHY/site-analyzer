什么是SSL证书？

SSL（Secure Sockets Layer）证书是一种数字证书，用于在网站和浏览器之间建立加密连接。安装SSL证书后，网站协议从 http:// 变为 https://，数据传输会被加密。

💡 类比理解

HTTP就像寄明信片——谁都能看到内容；HTTPS就像寄加密信件——只有收信人能打开。

为什么需要SSL证书？

  • 数据安全 — 加密传输，防止中间人窃听和篡改
  • SEO排名 — 百度、Google都优先收录HTTPS站点
  • 用户信任 — 浏览器显示"安全"锁标，提升转化率
  • 合规要求 — 涉及用户登录、支付等场景必须HTTPS
  • 现代Web功能 — HTTP/2、Service Worker等功能需要HTTPS

SSL证书类型

类型 验证方式 适用场景 价格
DV（域名验证） 验证域名所有权 个人网站、博客、工具站 免费/¥50-200
OV（企业验证） 验证企业身份 企业官网、电商平台 ¥1000-3000
EV（扩展验证） 严格的企业身份审核 银行、金融、支付平台 ¥2000-5000

对个人站长而言，DV证书完全够用。

免费SSL证书申请途径

1. Let's Encrypt（推荐 ⭐）

全球最流行的免费SSL证书颁发机构，被所有主流浏览器信任。

  1. 安装 Certbot：sudo apt install certbot python3-certbot-nginx
  2. 运行自动配置：sudo certbot --nginx -d www.bayihy.cn -d bayihy.cn
  3. Certbot 自动完成域名验证 + 证书部署 + nginx 配置
  4. 设置自动续期：Certbot 默认注册 systemd timer，每12小时检查

2. 云厂商免费SSL证书

  • 阿里云 — 控制台 → SSL证书 → 免费DV证书，每年可申请20张

3. Cloudflare CDN

使用Cloudflare作为CDN时，会自动提供免费的Universal SSL证书，无需手动配置。

付费SSL证书

如果网站是企业级应用或有特殊需求，可以考虑付费证书：

  • DigiCert — 行业标杆，兼容性最好
  • Sectigo（原Comodo） — 性价比高，支持多域名/Wildcard
  • GlobalSign — 国际知名CA，支持OV/EV证书
💡 续费提醒

免费SSL证书有效期通常为90天（Let's Encrypt）或1年（云厂商）。建议设置续费提醒或使用Certbot自动续期。

常见问题

Q1: SSL证书会影响网站速度吗？

首次HTTPS握手会有轻微延迟，但现代TLS 1.3协议已将影响降到极低。配合HTTP/2使用，HTTPS反而比HTTP更快。

Q2: 一个证书可以保护多个域名吗？

可以申请多域名证书（SAN）或通配符证书（*.example.com），覆盖多个子域名。

Q3: 证书过期了会怎样？

浏览器会显示"不安全"警告页面，用户可能不敢访问你的网站。务必设置自动续期！
