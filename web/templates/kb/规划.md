# 建站知识库规划

> 创建时间: 2026-07-23 · 维护者: Hermes + OpenClaw

## 🎯 定位

为"站长工具"站点补充**可索引的静态内容页**，解决百度眼里"纯工具站无内容"的问题，同时为新手提供建站科普。

## 📐 路由规划

| 路径 | 说明 |
|------|------|
| `/tools/kb/` | 知识库首页（分类导航） |
| `/tools/kb/light-server/` | 轻量服务器概念及申请途径 |
| `/tools/kb/domain-dns/` | 域名、DNS概念及申请途径 |
| `/tools/kb/icp-filing/` | ICP备案、ICP许可概念及申请方式 |
| `/tools/kb/gongan-beian/` | 公网安备概念及申请方式 |
| `/tools/kb/ssl-certificate/` | SSL证书概念及申请途径 |
| `/tools/kb/nginx-basic/` | Nginx基础概念 |
| ... | 后续可扩展 |

**设计原则：**
- 所有文章用 **Flask 模板渲染**，不硬编码nginx location（统一走 `/tools/kb/<slug>` 路由）
- 每篇文章独立HTML，SEO友好（纯静态HTML，有title/meta description/keywords）
- URL slug 使用英文短横线格式，便于记忆和分享

## 🎨 页面规范

### 每篇文章必须包含
- ✅ `<title>` 含关键词（如"什么是轻量服务器？- 建站知识库 - 巴依浩爷"）
- ✅ `<meta name="description">` 150字以内概括全文
- ✅ `<meta name="keywords">` 5-8个关键词
- ✅ `<meta name="robots" content="index, follow">`
- ✅ `<link rel="canonical">` 自引用
- ✅ 百度自动推送JS注入
- ✅ 面包屑导航（首页 > 知识库 > 文章标题）
- ✅ 上一篇/下一篇链接
- ✅ 目录导航（TOC，侧边或顶部）
- ✅ 底部"相关主题"推荐区

### 文章结构
```
# 标题
> 最后更新: 2026-07-23 · 阅读时间: X分钟

[引言段：一句话概括]

## 什么是XXX？
[解释]

## 为什么要用XXX？
[价值]

## 如何申请/使用？
[步骤]

## 常见问题
[FAQ]

---
← 上一篇 | 下一篇 →
```

## 🔧 技术实现

### Flask 路由
```python
@app.route('/kb/')
def kb_index():
    """知识库首页"""

@app.route('/kb/<slug>/')
def kb_article(slug):
    """知识库文章页"""
    template_map = {
        'light-server': 'kb/light-server.html',
        'domain-dns': 'kb/domain-dns.html',
        ...
    }
    return render_template(template_map[slug])
```

### Nginx
无需额外配置，统一走 `/tools/kb/` proxy_pass。

## 📊 SEO 优化

1. **内链强化**：每篇文章底部推荐相关主题
2. **面包屑导航**：利于百度理解站点结构
3. **sitemap**：所有kb文章加入sitemap.xml
4. **长尾词覆盖**：每篇文章600-1000字，覆盖"是什么/为什么/怎么做/FAQ"
5. **结构化数据**：JSON-LD Article schema
